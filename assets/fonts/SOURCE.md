# Bitsy Unicode Asian

- Original: https://github.com/le-doux/bitsy/blob/main/dev/resources/bitsyfont/unicode_asian.bitsyfont
- Original data is kept unchanged in `unicode_asian.bitsyfont`.
- `unicode-asian.js` contains the same glyphs as 18 integer row masks per character, for local `file://` use without fetch.
- Bitsy license: https://github.com/le-doux/bitsy/blob/main/LICENSE.md
