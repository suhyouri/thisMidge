# thismidge

8000 × 6000px의 네 단계 동심원 세계를 탐색하는 하루살이 인터랙션입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 설치나 빌드는 필요하지 않습니다.
위치 기능을 사용할 때 브라우저가 로컬 파일 접근을 제한하면 다음 서버로 실행하세요.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 두 휠 조작

왼쪽 휠은 ← / ↑, 오른쪽 휠은 ↓ / →에 대응합니다.

| 동시 입력 | 동작 |
| --- | --- |
| ← + ↓ | 왼쪽 회전 |
| ← + → | 전진 |
| ↑ + ↓ | 후진 |
| ↑ + → | 오른쪽 회전 |

한쪽 휠만 입력하면 곡선으로 이동합니다. 키를 놓으면 관성으로 감속합니다.
바람 아이콘을 눌러 위치를 허용하면 Open-Meteo의 풍향·풍속을 반영합니다.
위치는 소수점 두 자리로 줄여 조회하며, 파일이나 브라우저 저장소에 보관하지 않습니다.

## 이야기 편집

`text.js`의 `stage1`부터 `stage4`까지 문장을 입력합니다. 단계마다 25칸이 준비되어 있으며,
빈 문자열은 제외됩니다. 항목을 추가하거나 삭제해도 됩니다.
저장하고 새로고침하면 적용됩니다.

각 단계에는 원형 트리거가 3개씩 있습니다. 닿으면 해당 단계의 문장을 무작위로 보여주며,
문장은 5초 후 자동으로 닫힙니다. 한 단계의 문장을 모두 읽기 전까지 중복 선택하지 않습니다.
다시 원에 닿거나 클릭하면 다음 문장이 표시됩니다.

## 파일

- `index.html`, `style.css`: 화면 구성
- `flight.js`: 두 휠 조작, 관성, 카메라, 경계 이동
- `world.js`: 네 단계, 이야기 트리거, 자동 대화창, 화이트아웃
- `text.js`: 작성할 문장
- `wind.js`: 현재 위치의 바람 조회
- `dither.js`: 하루살이 픽셀 렌더링
- `bitmap-text.js`, `fonts/`: Bitsy Unicode Asian 원본 비트맵 폰트 렌더링

폰트 원본과 출처는 `fonts/SOURCE.md`를 참고하세요.
